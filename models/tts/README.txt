Piper TTS — локальные модели для «Зевса»
===========================================

Зевс озвучивает текст через локальную нейросетевую модель Piper.
Модель полностью офлайн, интернет не требуется.

ЧТО ПОЛОЖИТЬ СЮДА
-----------------
Два файла (имя одинаковое, кроме расширения):
  - voice.onnx       — веса нейросети
  - voice.onnx.json  — конфигурация модели
Вот и всё. Если файлов нет, Зевс автоматически озвучивает через
системный pyttsx3 (SAPI5) — приложение продолжит работать.

ГДЕ ВЗЯТЬ МОДЕЛЬ (русские голоса)
----------------------------------
Официальные модели rhasspy/piper-voices (репозиторий Hugging Face):
  https://huggingface.co/rhasspy/piper-voices/tree/main/ru

Русские голоса:
  - ru_RU-denis-medium    мужской (рекомендуется для «Джарвиса»)
  - ru_RU-irina-medium    женский

На странице внутри папки голоса нажмите на файл:
  - ru_RU-denis-medium.onnx
  - ru_RU-denis-medium.onnx.json
и скачайте их (кнопка Download), затем переименуйте в voice.onnx /
voice.onnx.json и положите сюда.

НАСТРОЙКИ (data/settings.json -> voice_settings)
-------------------------------------------------
  "tts_engine": "piper"                     # "piper" или "pyttsx3"
  "piper_model": "models/tts/voice.onnx"    # путь к модели
  "piper_length_scale": 0.9                 # темп: <1.0 быстрее, >1.0 медленнее
  "piper_noise_scale": 0.6                  # «ровность» голоса

СОВЕТ: если модель не проговаривает цифры/пунктуацию — попробуйте
другой голос того же языка.
